## mcpd config volumes remove

Remove volume mappings from an MCP server

### Synopsis

Remove volume mappings from an MCP server in the runtime context configuration file (e.g. /Users/pwilson/.config/mcpd/secrets.dev.toml).

Use -- to separate the server name from the volume names to remove.

Examples:
  # Remove a single volume mapping
  mcpd config volumes remove filesystem -- --workspace

  # Remove multiple volume mappings
  mcpd config volumes remove filesystem -- --workspace --gdrive

```
mcpd config volumes remove <server-name> -- --<volume-name> [--<volume-name>...] [flags]
```
